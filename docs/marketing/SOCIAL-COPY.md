## Developer community / Reddit / forum introduction

**Title:** Building a small Omarchy search palette with explicit ChatGPT/local Q&A — public v1 preview

I maintain Model Search, a keyboard-first Omarchy palette for application/filename search and deliberately selected AI Q&A. This is a project-owner introduction, not an independent review.

The current lab candidate has direct ChatGPT sign-in, local loaded-model discovery, and an optional no-tools jcode route through LM Studio. Unsafe native CLI execution stays disabled. It does not silently switch providers or download models.

75 offline tests and the synthetic isolation/lifecycle checks pass. Live model responses, latency and quality are not yet verified, so I am sharing this as a preview rather than calling it production-ready.

I would value feedback on the workflow: how visible should provider selection be in a keyboard palette, and what makes local-vs-cloud routing clear without adding clutter?
