# Model Search media kit

**Find locally. Ask deliberately.**

Model Search is an independent, keyboard-first Omarchy palette for local name search and explicitly selected AI Q&A. It keeps the destination visible and avoids silent provider fallback.

Current campaign: **private v1 preview**, version 1.0.0-rc.1. The repository has not been approved for public release. Social copy is prepared, not evidence of publication. Do not imply public access to a private link.

## Product brief

**Audience:** Omarchy users who prefer keyboard workflows and deliberate control over cloud versus local questions.

**Value:** one familiar palette for local application/file-name search and an explicit route into Q&A, without automatically pulling models or adding agent tools.

**Differentiators:** ordinary search independent of AI; provider/model selection before submission; no silent fallback; blocked routes stay blocked; owner-approved downloads; separately managed runtimes.

**Proof available:** 75 offline tests, verified sign-in/catalog persistence, loaded-model discovery, real-jcode synthetic isolation tests, VM lifecycle and visual checks. No real inference/latency/quality claim yet.

**Maintainer:** mapski. Independent community project, not an official OpenAI, LM Studio or Omarchy product. No fabricated customer counts, endorsements, awards, testimonials or benchmark wins.

## Visual system

Midnight `#080E20`, warm apricot `#FFBF8C`, pale ink `#F8EDE0`, secondary ink `#B9C2D5`, restrained lilac accent `#C6B4FF`. Use open space, clear type hierarchy and real interface evidence. The original mark combines a search lens with a small crosshair. System sans-serif and monospace font fallbacks avoid font downloads.

Keep the **private preview** label on every current campaign asset. Never retouch a screenshot to imply an unimplemented feature. Do not disguise concept art as the current UI.
